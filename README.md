# Summary

CSC250 is DSU's Computer Science II class equivalent. The course is taught in strict C.

## Assignment 1

This assignment is a simple collection of rather basic concepts students encounter very early in their programming journey, seemingly intended as a refresher more than anything challenging.

## Assignment 2

The assignment challenged students to create a very simple hangman-style game without any genuine input validation requirements.

## Assignment 3

This assignment had students build a simple game of Tic Tac Toe. The lesson introduced students to custom header files and simple functional decomposition. The assignment itself had fairly rudimentary requirements and otherwise required almost not input validation or error handling.

## Midterm Coding "Challenge"

This is an exceptionally simple program that parses a sequence of temperatures from a text file then splits them into low and high temperatures in both Fahrenheit and Celsius for each day of the week.
